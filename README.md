# Landing Básica

Primera landing page creada con HTML, CSS y JavaScript.

## Descripción

Este proyecto es una página web simple para presentar servicios web profesionales. Incluye secciones de servicios, beneficios y contacto.

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades

- Diseño responsive
- Menú de navegación
- Sección de servicios
- Formulario de contacto
- Alerta al enviar formulario
